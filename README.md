# ashfall-dnd

I am a bad DM at D&D, so I made this to be slightly better at running my original campaign.

This repo has the campaign guide, the scripts that turn it into site content, and the small DM control room I use at the table. It is plain HTML, CSS and JavaScript, so there is no build step.

Run it locally with `python -m http.server 8000`, then open `http://localhost:8000`. Changes pushed to `main` are deployed to GitHub Pages.
